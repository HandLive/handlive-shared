# CLAUDE.md — handlive-shared

The shared data of HandLive: test vectors, JSON schemas, design tokens, the UI string catalog and the Python tools that generate and check them. Android, Apple and the relay all read it. One part of the HandLive **workspace**: the hub repository `handlive` is this directory's parent, holds the specs these files are derived from, and its `CLAUDE.md` applies here in full.

## Workspace layout (mandatory)

```
<workspace>/        hub repo "handlive": CLAUDE.md (read first), docs/detailed-design/ (the source of everything here), docs/design-system/
  shared/           this repo (handlive-shared)
  android/ apple/ relay/   the platform repos; their build scripts and tests read ../shared
```

`tools/schemas/check_schemas.py` reads `../docs/detailed-design` (override with `HANDLIVE_DOCS_DIR`). From the hub, `tools/workspace.sh clone <group-url>` checks the parts out.

## Contents

- `test-vectors/*.json` — generated by `tools/vectors/generate_vectors.py`, never edited by hand; `envelope-roundtrip*.json` are written by the Android and Apple crypto tests (`HL_WRITE_ROUNDTRIP=1`).
- `schemas/*.schema.json` — JSON Schema 2020-12 for the envelope, ack, error, `session/*` and `capability/*` payloads.
- `design-tokens/tokens.json` (+ `type-extras.json`) — the design system tokens; `tokens.json` must stay byte-identical with `../docs/design-system/tokens.json` in the hub (the Design System artifact source): change both, each in its own repository.
- `tools/vectors/`, `tools/schemas/` — run from this repository root with the venv `tools/.venv` (`python3 -m venv tools/.venv && tools/.venv/bin/pip install -r tools/vectors/requirements.txt -r tools/schemas/requirements.txt`).

## Working here

- Every change here is a contract change. Order: update `../docs/detailed-design/00-common-specs.md` (and the leaf spec) in the hub, run `python3 ../tools/docs/validate_design_docs.py` there (`problems=0`), then change the builders in `tools/vectors/build_*.py` or the schema, regenerate (`tools/.venv/bin/python tools/vectors/generate_vectors.py`), verify (`… verify_vectors.py` must print `0 lỗi`, `… generate_vectors.py --check` `0 lệch`, `… tools/schemas/check_schemas.py` `XANH`).
- Report every change here in the task report so the Android, Apple and relay agents re-run their tests; the platform CIs do not run when only this repo changes (start them by hand).
- Commit early and small, conventional commits (`feat(shared): …`, `fix(shared): …`, `test(shared): …`), no AI references. A commit never spans repositories: commit here first, then the platform that consumes the change.
